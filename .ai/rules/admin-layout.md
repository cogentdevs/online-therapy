# Admin Layout

## Use the single adminLayout master
Keep the admin master and partials in resources/views/layouts/adminLayout/: admin-design.blade.php, admin-header.blade.php, admin-sidebar.blade.php, and admin-footer.blade.php. Admin pages extend admin-design; do not move these files or create a second admin master layout.
